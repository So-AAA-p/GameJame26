WHAT'S INSIDE
-------------
- CookedSans-Regular.ttf   TrueType — use this for games and most apps

- preview.png              Character overview
- LICENSE.txt              Free for personal and commercial use

ABOUT THE DESIGN
----------------
A rounded, monoline sans with soft squircle bowls, square-ish inner shoulders,
a curled l and single-storey a and g. Clean enough for body text and menus,
friendly enough for titles and HUDs. 413 hand-tuned kerning pairs.
Made to pair with Softline Game UI Icons and the Softline UI Kit.

CHARACTER SET (335 glyphs)
--------------------------
A–Z, a–z, 0–9, all ASCII punctuation, symbols (€ ₺ £ ¥ © ® ™ § ¶ « » „ “ …),
superscripts and fractions (¹ ² ³ ¼ ½ ¾)
Full Latin-1 and Latin Extended-A: Turkish, French, German, Spanish,
Portuguese, Italian, Polish, Czech, Slovak, Hungarian, Romanian, Nordic
and many more European languages.

INSTALL
-------
Windows : right-click the .ttf -> Install
macOS   : double-click the .ttf -> Install Font
Unity   : drag the .ttf into Assets, then create a TextMeshPro Font Asset
          (Window > TextMeshPro > Font Asset Creator)
Godot   : drag the .ttf into the project and use it in a Theme or Label
Unreal  : import the .ttf and create a Font asset
